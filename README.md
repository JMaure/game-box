A personal project of a website that includes several games such as tic-tac-toe, minesweeper, and snake. 
This project was created to practice the skills I learned during my React training.

https://game-box-one.vercel.app/

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
